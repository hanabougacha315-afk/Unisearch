# UniSearch

**University Information Retrieval System**

UniSearch est une application Web de recherche documentaire universitaire permettant aux étudiants de retrouver facilement des cours, TD, TP et examens à partir de mots-clés.

## Objectif du projet

Développer un système de recherche d'information reposant sur les techniques suivantes :

- Analyse lexicale
- Tokenisation
- Élimination des Stop Words
- Normalisation linguistique
- Indexation automatique
- Fichier inversé
- Pondération TF-IDF
- Similarité cosinus

## Technologies utilisées

- Java
- Spring Boot
- MySQL
- Spring Data JPA
- Thymeleaf
- HTML, CSS, JavaScript et Bootstrap
- Apache PDFBox

## Fonctionnalités principales

- Recherche documentaire publique sans authentification
- Gestion des documents par les enseignants et administrateurs
- Extraction automatique du texte des PDF
- Prétraitement linguistique français
- Construction d'un index inversé
- Classement des résultats par pertinence
- Téléchargement des documents
